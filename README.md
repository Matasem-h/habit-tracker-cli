# Habit Tracker CLI

A command-line habit tracker built in Python, using object-oriented programming for the habit model, functional programming for the analytics, SQLite for storage, and click for the command-line interface.

This is a university portfolio project for the course *Object-Oriented and Functional Programming with Python* (IU International University of Applied Sciences).

> **Status:** in development. Full installation and usage instructions will be added as the project is completed.

## Running the tests

```
pip install -r requirements.txt
python -m pytest
```
